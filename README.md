# Pole

Каталог небольшой керамической мастерской: фильтры, карточка и сравнение до трёх позиций.

Данные выдуманные. Задача проекта — показать работу со списком, адресом страницы и ограничением в интерфейсе, а не нарисовать ещё один лендинг.

## Стек

React, TypeScript, Vite, React Router, Vitest.

## Как устроено

Фильтры и состав сравнения лежат в query-строке. Карточка открывается по `/p/:id` и забирает те же параметры, поэтому «назад в каталог» возвращает тот же срез, а не пустую витрину.

В сравнение нельзя добавить четвёртую позицию: функция `toggleCompare` отклоняет клик, интерфейс показывает причину. Это правило покрыто тестом, вместе с ценовыми полками и поиском.

Цена, глазурь, диаметр и срок собираются в нижнюю таблицу только из выбранных id. Отдельного глобального стора нет: источник правды — URL.

## Что говорить на собеседовании

- Сравнение и фильтры сериализованы в адрес. Обновление страницы не сбрасывает выбор.
- Ограничение «не больше трёх» живёт в чистой функции, поэтому его можно проверить без браузера.
- Карточка не дублирует каталог: тот же query уходит в `Link`, и пользователь не теряет фасеты.
- Список маленький и локальный. Если бы он приходил с API, фильтр по текстовому поиску можно оставить на клиенте, а фасеты — отдать серверу. Сейчас граница проведена явно: данные константа, правила отдельно от вёрстки.
